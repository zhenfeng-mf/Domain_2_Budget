# Budget App

A Ruby on Rails application built with Rails 8 and MySQL 9.

## Requirements & Stack

* **Ruby:** 3.2.3 (or as specified in `.ruby-version`)
* **Rails:** 8.0+
* **Database:** MySQL 9.0+ (managed via Docker Compose)
* **Docker & Docker Compose**
